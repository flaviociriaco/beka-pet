# Beka Pets — Landing Page Institucional

Projeto de site responsivo criado para a Beka Pets com o objetivo de apresentar a marca, os serviços de banho, tosa e atendimento veterinário, além de facilitar o contato direto com os tutores.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Layout responsivo construído com Flexbox, CSS Grid e variáveis CSS para tematização.
* **Font Awesome:** Ícones vetoriais integrados para redes sociais e informações de contato.
* **Google Maps API (Embed):** Mapa de localização interativo da unidade.

## ✨ Recursos
* Design totalmente responsivo (mobile-first).
* Integração de clique direto para conversa no WhatsApp.
* Seções de Apresentação, Serviços, Depoimentos, Localização e Contato.
